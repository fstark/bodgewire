# Heartbeat

## What it does

Connect +5 V to `J1`. The sixteen LEDs in the front row show the address the processor is reading, the highest bit on the left (`D16`). With the processor running, `D16` blinks about 7.6 times a second, `D15` twice as fast, `D14` flickers and the others glow. `RESET` (`SW1`) restarts the processor.
