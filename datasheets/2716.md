# 2716 — 2K x 8 EPROM

## Function

A memory of 2048 bytes, written once by a programmer and kept with the power off. The byte at the address on `A0`–`A10` appears on `O0`–`O7` about 450 ns after the address settles, while `CE_N` and `OE_N` are both low. Otherwise the outputs are off (floating), so that several memories can share the same data lines.

`VPP` is the programming voltage: on a Board that only reads the memory, it is tied to `VCC`.

Its contents come from the file that `contents=` names. With `offset=` (a multiple of the chip's size, `$hex` or decimal), the chip holds only the slice of a larger `.rom` text file that starts there: one program can fill several sockets, as the BW-2001's BASIC fills `$C000` and `$C800`. Words the file never wrote are erased (`$FF`). A raw `.bin` dump is one chip and takes no offset.

## Pins

- `A0`–`A9`, `A10`: address; `A0` is the lowest bit
- `O0`–`O7`: data out; `O0` is the lowest bit
- `CE_N`: chip enable, active low
- `OE_N`: output enable, active low; the outputs come on about 120 ns after it falls
- `VPP`: programming voltage, tied to `VCC` to read
- `VCC`: +5 V
- `GND`: 0 V
