# 7417 — hex buffer, open collector

## Function

Six separate buffers. Each output follows its input, but it can only pull down: a low input pulls the output low, and a high input releases it, so something else must pull it up (a resistor). Several open-collector outputs can share one line, and any one of them pulling low makes it low. On the PET 2001 they buffer the address lines to the memory and the expansion connector, each with its own pull-up resistor.

## Pins

- `1A`–`6A`: inputs
- `1Y`–`6Y`: outputs, open collector
- `VCC`: +5 V
- `GND`: 0 V
