# 74LS05 — hex inverter, open collector

## Function

Six separate inverters whose outputs can only pull down. A high input pulls its output low; a low input releases it, so something else must pull it up (a resistor). Several open-collector outputs can share one line, and any one of them pulling low makes it low.

On the ZX80, eight of them force a NOP onto the CPU's data lines while the RAM shows a character code behind the data bus resistors, and two in parallel drive the CPU clock with a 330 Ω pull-up.

## Pins

- `1A`–`6A`: inputs
- `1Y`–`6Y`: outputs, open collector
- `VCC`: +5 V
- `GND`: 0 V
