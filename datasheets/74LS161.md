# 74LS161 — synchronous 4-bit binary counter

## Function

A counter that steps 0, 1, 2, ... 15, 0 on each rising edge of `CLK`. Its value appears on `QA` (bit 0, toggles fastest) to `QD` (bit 3, slowest). Each output runs at half the frequency of the one before: with a 1 MHz clock, `QA` is 500 kHz, `QB` 250 kHz, `QC` 125 kHz, `QD` 62.5 kHz.

On each rising clock edge, in this order of priority:

- `CLR_N` low: the count is 0 at once, without waiting for the clock
- `LOAD_N` low: the count becomes the value on `A`–`D`
- `ENP` and `ENT` both high: the count goes up by one
- otherwise: the count holds

`RCO` (ripple carry out) is high while the count is 15 and `ENT` is high. Wiring `RCO` to the `ENT` of a second counter makes the two count together as one 8-bit counter.

## Pins

- `CLK`: clock; the count changes on its rising edge
- `CLR_N`: clear, active low
- `LOAD_N`: load `A`–`D` on the next clock, active low
- `A`–`D`: value to load
- `ENP`, `ENT`: count enables; both high to count
- `QA`–`QD`: the count, `QA` lowest bit
- `RCO`: ripple carry out, high at count 15
- `VCC`: +5 V
- `GND`: 0 V
