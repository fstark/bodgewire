# 74LS154 — 4-to-16 line decoder

## Function

Turns a 4-bit number on `D` `C` `B` `A` into one of sixteen outputs. While both enables `G1_N` and `G2_N` are low, the output with that number is low and the other fifteen are high. If either enable is high, all sixteen are high. On the PET 2001 the top four address lines go to `A`–`D`, so each output is low for one 4 KB block of the address space: `Y8_N` for the screen memory at `$8000`, `Y12_N` to `Y15_N` for the ROMs. An output changes about 23 ns after the number does and 19 ns after an enable.

## Pins

- `A`, `B`, `C`, `D`: the number, `A` the lowest bit
- `Y0_N`–`Y9_N`, `Y10_N`–`Y15_N`: outputs, low when selected
- `G1_N`, `G2_N`: enables, both low to select an output
- `VCC`: +5 V
- `GND`: 0 V
