# 74LS30 — 8-input NAND

## Function

One NAND gate with eight inputs. The output is low only when all eight inputs are high; if any input is low, the output is high. Unused inputs are tied high so they do not block the others.

## Pins

- `A`–`H`: the eight inputs
- `Y`: output
- `NC9`, `NC10`, `NC13`: not connected inside the chip
- `VCC`: +5 V
- `GND`: 0 V
