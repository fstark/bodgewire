# 74177 — presettable binary counter/latch

## Function

A 4-bit counter in two parts. Flip-flop A changes state each time `CLK1` falls. Flip-flops B, C and D count from 0 to 7 each time `CLK2` falls, one after another: B first, then C, then D, each a little later (a ripple counter). Wiring `QA` to `CLK2` makes one counter of 0 to 15.

`CLR_N` low sets every output low at once, whatever else happens. `CT_LOAD_N` low makes each output follow its data input (`A` to `QA`, …, `D` to `QD`) at once, like a latch; the value stays when it goes high again, and counting goes on from there. Counting happens only while both are high.

On the PET 2001, two of them count the screen memory address, and a load starts each line of characters over.

## Pins

- `CLK1`: clock of flip-flop A, counts on its falling edge
- `CLK2`: clock of flip-flops B, C and D, counts on its falling edge
- `QA`, `QB`, `QC`, `QD`: outputs, `QA` the lowest bit
- `A`, `B`, `C`, `D`: data inputs, loaded while `CT_LOAD_N` is low
- `CT_LOAD_N`: count while high, load while low
- `CLR_N`: clear, active low
- `VCC`: +5 V
- `GND`: 0 V
