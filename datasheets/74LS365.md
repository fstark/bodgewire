# 74LS365 — hex buffer, tri-state, two enables

## Function

Six one-way buffers that share two enables. While `G1_N` and `G2_N` are both low, each of `Y1`–`Y6` copies its input among `A1`–`A6`. While either is high, all six outputs are off (floating), so that other chips can drive the same lines.

On the ZX80 both enables are on the keyboard read signal: an `IN` from an even port puts the five keyboard lines and the cassette input onto the data bus.

## Pins

- `A1`–`A6`: inputs
- `Y1`–`Y6`: outputs
- `G1_N`, `G2_N`: output enables, active low; both low turns the outputs on
- `VCC`: +5 V
- `GND`: 0 V
