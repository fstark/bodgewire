# 74LS27 — triple 3-input NOR

## Function

Three separate NOR gates with three inputs each. An output is high only when all three of its inputs are low; if any input is high, the output is low. With one input tied to 0 V, a gate is a plain 2-input NOR.

Gate 1 is split across the package: its inputs `1A` and `1B` are pins 1 and 2, but its third input `1C` is pin 13 and its output `1Y` pin 12.

## Pins

- `1A`, `1B`, `1C`: inputs of gate 1 (pins 1, 2, 13)
- `1Y`: output of gate 1 (pin 12)
- `2A`–`2C`: inputs of gate 2
- `2Y`: output of gate 2
- `3A`–`3C`: inputs of gate 3
- `3Y`: output of gate 3
- `VCC`: +5 V
- `GND`: 0 V
