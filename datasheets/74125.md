# 74125 — quad bus buffer, tri-state

## Function

Four one-way buffers, each with its own enable. While `1OE_N` is low, output `1Y` copies input `1A`; while `1OE_N` is high, `1Y` is off (floating), so that other chips can drive the same line. Buffers 2 to 4 work the same, each with its own enable. On the KIM-1, two of them put the eight 6102s' outputs on the data bus, only while the processor reads that memory.

## Pins

- `1A`, `2A`, `3A`, `4A`: inputs
- `1Y`, `2Y`, `3Y`, `4Y`: outputs
- `1OE_N`, `2OE_N`, `3OE_N`, `4OE_N`: output enables, active low
- `VCC`: +5 V
- `GND`: 0 V
