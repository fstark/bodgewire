# 74LS20 — dual 4-input NAND

## Function

Two separate NAND gates with four inputs each. An output is low only when all four of its inputs are high; if any input is low, the output is high. Often used as a decoder: it spots one exact combination of four signals.

## Pins

- `1A`–`1D`: inputs of gate 1
- `1Y`: output of gate 1
- `2A`–`2D`: inputs of gate 2
- `2Y`: output of gate 2
- `NC3`, `NC11`: not connected inside the chip
- `VCC`: +5 V
- `GND`: 0 V
