## Front end

`asm6502.cpp`'s `Assembler` class becomes the front end in `assembler.cpp`, unchanged except where named here. It no longer knows a mnemonic: a statement that is not a label, constant or directive goes to the current `InstructionSet`.

```cpp
// instruction_set.hpp (internal to bw_asm)
struct AsmError { std::string message; };
[[noreturn]] void Fail(std::string message);
struct AsmValue { std::int64_t number = 0; bool known = true; };  // was Value
std::string Upper(std::string_view);  std::string_view Trim(std::string_view);
bool IsIdentStart(char);  bool IsIdentChar(char);
std::size_t CharLiteralAt(std::string_view, std::size_t);  // a 'c' literal's length, or 0
std::vector<std::string_view> SplitArguments(std::string_view);  // commas outside "", 'c', ()
std::string Squeeze(std::string_view);  // blanks out, upper case, outside 'c'

class AsmContext {  // the front end, seen by an instruction set
public:
    virtual int pass() const = 0;                          // 1 or 2
    virtual std::int64_t pc() const = 0;                   // Fail("instruction before any .org")
    virtual AsmValue expression(std::string_view text) = 0;
    virtual void emit(std::uint8_t byte) = 0;
    virtual void check(AsmValue v, std::int64_t low, std::int64_t high,
                       std::string_view what) = 0;         // pass 2 only, as checkKnownRange
    virtual int& memo() = 0;  // one int per source line, kept from pass 1 to pass 2
protected:
    ~AsmContext() = default;
};

class InstructionSet {
public:
    virtual bool knows(std::string_view upperMnemonic) const = 0;
    virtual void assemble(AsmContext& context, std::string_view upperMnemonic,
                          std::string_view operands) const = 0;
protected:
    ~InstructionSet() = default;
};
```

- Namespace `bw::asm_detail`; the helpers are defined in `assembler.cpp` (today in its anonymous namespace; `StripComment` stays there, only the front end uses it).
- `memo()` replaces the 6502's `forms_` vector (its form as an int); the Z80 does not use it.
- `.cpu NAME` (`Upper(NAME)` `6502` or `Z80`): `unknown CPU 'x'`; given after an instruction or a second time in pass 1: `.cpu must come before any instruction` / `.cpu given twice`. Pass 2 resets the CPU to the 6502 at its start, as `pc_`, and meets the same `.cpu`.
- `instruction()` keeps the front end's checks: an empty word or one `knows()` refuses → `unknown instruction '<word>'` (the word as written). The 6502's error order is kept: unknown mnemonic, then no form, then `instruction before any .org` (`pc()` asked only after the opcode is found).
- `symbolName` and `primary` unchanged: a register name in an operand is decided by the instruction set before an expression is parsed, so a symbol named `B` is never read in an operand the Z80 parses as a register (the recipe's note).
- Public API, `assembler.hpp`: `AssembledRom` as today; `Assemble(source, file, includeDir = nullopt)`, `AssembleFile(path)`; the header comment holds the syntax of both CPUs (the 6502's as today, then the Z80's in the same short form: What is new 1 of the spec).

Phase 1 moves code and renames only: every committed `.rom` is unchanged (`asm_*`, `asm: every ROM program…`).

## Z80 instructions (`asmz80.cpp`)

### Operands

`Operand Parse(std::string_view text, bool conditionFirst)` classifies one argument of `SplitArguments` on its `Squeeze`d text, but takes every expression (the `At` inside, the `AtIndex` displacement with its sign, the `Imm` text) from the original argument: symbols are case-sensitive, as on the 6502 side. The kinds, tried in this order (`Cond` first when `conditionFirst`, so `JP C,x` and `RET C` read the condition):

| Kind | Text | Value |
|---|---|---|
| `Cond` | `NZ Z NC C PO PE P M`, only when `conditionFirst` | code 0–7 |
| `Reg8` | `B C D E H L A` | code 0–5, 7 |
| `Special` | `I`, `R` | |
| `Pair` | `BC DE HL SP AF` | |
| `Index` | `IX`, `IY` | prefix `$DD`/`$FD` |
| `AltAf` | `AF'` | |
| `AtHl`, `AtBc`, `AtDe`, `AtSp`, `AtC` | `(HL) (BC) (DE) (SP) (C)` | |
| `AtIndex` | `(IX)`, `(IX+e)`, `(IX-e)` and `IY`: `(` + `IX`/`IY` + nothing, or `+`/`-` and an expression, + `)` closing at the end | prefix, displacement text (`-` kept in front) |
| `At` | starts with `(` whose matching `)` is the last character | the expression inside |
| `Imm` | anything else | the whole text as an expression |

`conditionFirst` is true for the first operand of `JP`, `CALL`, `JR` and `RET`, whatever their count: `JP C` is `JP has no form 'C'`, `JP Z` a condition, never the symbol `Z`. A register or condition name inside a longer expression is an ordinary symbol (with `C = 5`, `LD A,C+1` loads 6, `LD A,C` reads register C): no error, the recipe's note. The `(… )` matching uses `SplitArguments`' rules (quotes and `'c'` skipped).

`AF'`: `StripComment` and `SplitArguments` see `'` as a `'c'` literal only when the character two places on is `'`, so `EX AF,AF' ; it's` stays whole; a test holds it.

### Form table

A `Form` row: mnemonic, up to two operand patterns, and a byte template. Patterns: `r` (`Reg8`), `(HL)`, `(XY+d)` (`AtIndex`), `n` (`Imm`, 8-bit), `nn` (`Imm`, 16-bit), `(nn)` (`At`, address), `(n)` (`At`, port), `dd` (`BC DE HL SP`), `qq` (`BC DE HL AF`), `ss`-with-index `pp` (`BC DE XY SP`, the `XY` that of the first operand), `XY` (`Index`), `cc` (all 8), `jc` (`NZ Z NC C`), `e` (`Imm`, relative), `b` (`Imm` 0–7), `im` (`Imm` 0–2), `p` (`Imm`, `RST`), and literal operands (`A`, `I`, `R`, `HL`, `DE`, `AF`, `AF'`, `SP`, `(BC)`, `(DE)`, `(SP)`, `(C)`). The template: optional prefix (`ED`, `CB`, or the index's `DD`/`FD`), the opcode as a base plus each field shifted to its place (`r` into bits 3–5 or 0–2, `dd`/`qq`/`pp` into 4–5, `cc` into 3–5, `b` into 3–5, `im`'s 0/1/2 to `$46 $56 $5E`, `p` added), then the operand bytes in the chip's order: displacement before an immediate (`DD 36 d n`), `DD CB d op` for the `CB` index forms, `nn` low byte first.

The rows, from UM0080 (`r`, `r'` are `Reg8`; `s` is `r`, `n`, `(HL)`, `(XY+d)`; `m` in the rotate rows is `r`, `(HL)`, `(XY+d)`):

- 8-bit load: `LD r,r'` 40; `LD r,n` 06; `LD r,(HL)` 46; `LD r,(XY+d)` XY 46; `LD (HL),r` 70; `LD (XY+d),r` XY 70; `LD (HL),n` 36; `LD (XY+d),n` XY 36; `LD A,(BC)` 0A; `LD A,(DE)` 1A; `LD A,(nn)` 3A; `LD (BC),A` 02; `LD (DE),A` 12; `LD (nn),A` 32; `LD A,I` ED 57; `LD A,R` ED 5F; `LD I,A` ED 47; `LD R,A` ED 4F.
- 16-bit load: `LD dd,nn` 01; `LD XY,nn` XY 21; `LD HL,(nn)` 2A; `LD dd,(nn)` ED 4B (BC, DE, SP; HL takes the 2A row); `LD XY,(nn)` XY 2A; `LD (nn),HL` 22; `LD (nn),dd` ED 43 (BC, DE, SP); `LD (nn),XY` XY 22; `LD SP,HL` F9; `LD SP,XY` XY F9; `PUSH qq` C5; `PUSH XY` XY E5; `POP qq` C1; `POP XY` XY E1.
- Exchange, block: `EX DE,HL` EB; `EX AF,AF'` 08; `EXX` D9; `EX (SP),HL` E3; `EX (SP),XY` XY E3; `LDI` ED A0, `LDIR` B0, `LDD` A8, `LDDR` B8, `CPI` A1, `CPIR` B1, `CPD` A9, `CPDR` B9.
- 8-bit arithmetic: `ADD A,s` 80/C6, `ADC A,s` 88/CE, `SUB s` 90/D6, `SBC A,s` 98/DE, `AND s` A0/E6, `XOR s` A8/EE, `OR s` B0/F6, `CP s` B8/FE (register/`(HL)` base, immediate opcode; `(XY+d)` the register base + 6 behind XY); `INC r` 04, `INC (HL)` 34, `INC (XY+d)` XY 34; `DEC r` 05, `DEC (HL)` 35, `DEC (XY+d)` XY 35.
- General: `DAA` 27, `CPL` 2F, `NEG` ED 44, `CCF` 3F, `SCF` 37, `NOP` 00, `HALT` 76, `DI` F3, `EI` FB, `IM im` ED 46/56/5E.
- 16-bit arithmetic: `ADD HL,dd` 09; `ADC HL,dd` ED 4A; `SBC HL,dd` ED 42; `ADD XY,pp` XY 09; `INC dd` 03; `INC XY` XY 23; `DEC dd` 0B; `DEC XY` XY 2B.
- Rotate and shift: `RLCA` 07, `RLA` 17, `RRCA` 0F, `RRA` 1F; `RLC m` CB 00, `RRC m` CB 08, `RL m` CB 10, `RR m` CB 18, `SLA m` CB 20, `SRA m` CB 28, `SRL m` CB 38 (`(XY+d)`: XY CB d op+6); `RLD` ED 6F, `RRD` ED 67.
- Bit: `BIT b,m` CB 40, `SET b,m` CB C0, `RES b,m` CB 80 (`m` as the rotates).
- Jump: `JP nn` C3; `JP cc,nn` C2; `JR e` 18; `JR jc,e` 20 (NZ 20, Z 28, NC 30, C 38); `JP (HL)` E9; `JP (XY)` XY E9 (`(IX)` with no displacement only); `DJNZ e` 10.
- Call, return: `CALL nn` CD; `CALL cc,nn` C4; `RET` C9; `RET cc` C0; `RETI` ED 4D; `RETN` ED 45; `RST p` C7 + p.
- Input, output: `IN A,(n)` DB; `IN r,(C)` ED 40; `INI` ED A2, `INIR` B2, `IND` AA, `INDR` BA; `OUT (n),A` D3; `OUT (C),r` ED 41; `OUTI` ED A3, `OTIR` B3, `OUTD` AB, `OTDR` BB.

`LD (HL),(HL)` (that is `HALT`) and `LD (XY+d),(HL)` match no row. A `(XY+d)` row's other `Reg8` operand stays the real register (`LD H,(IX+1)` is `DD 66 01`): the documented meaning.

`assemble()` parses the operands, finds the first row whose patterns match (the rows tried in the order above), and emits; no match → `LD has no form 'B,(SP)'` (the operands as `Squeeze` gives them: upper case, no blanks). A mnemonic with rows but the `A,` missing or extra (`ADD B`, `SUB A,B`) gets that message too, followed by `(Zilog: ADD A,s)` / `(Zilog: SUB s)`.

### Values

Through `context.check` in pass 2 (pass 1 sizes need no values): `n` −128..255 `"immediate"`; `nn` −32768..65535 `"immediate"`; `(nn)`, `JP`/`CALL` targets 0..$FFFF `"address"`; `(n)` 0..255 `"port"`; `d` −128..127 `"displacement"`; `e`: the target 0..$FFFF, then `target − (pc + 2)` −128..127 or `relative jump out of range (N bytes)`; `b` 0..7 `"bit"`; `im` 0..2 `"interrupt mode"`; `p` one of `$00 $08 … $38` or `RST needs $00, $08, ... $38`. Negative values are emitted as their low byte or word.

## Tests

`tests/asm/asmz80_test.cpp`, tag `[asm]`, every case named `asm z80: …` (the fences' `-R asm` matches names, not tags). Its own helpers (the 6502 ones are file-local and strip trailing `$FF`s, which `RST $38` and `LD HL,-1` end with): over a `.cpu z80`, `.rom $0000, $1000`, `.org $0100` header, `Z80Bytes(body)` reads the bytes back from the `.rom` text's `@…` rows (the header emits none, so they are exactly the body's, `$FF`s included); `Z80Error(body)` as the 6502's `Error`.

- **Hand table**: `{text, bytes}` rows, one per form of the table above (each register group once, a register in each field position, both index registers, a negative displacement, every condition kind, `JR`/`DJNZ` back and forward, every block and I/O instruction, `IM` 0/1/2, `RST $38`), the bytes typed from UM0080 (not from the form table).
- **Disassembler round trip**: `tests/asm/z80_disassembler.{hpp,cpp}`: `struct Z80Text { std::string text; std::size_t length; };` `std::optional<Z80Text> DisassembleZ80(std::span<const std::uint8_t> bytes, std::uint16_t at)`, `nullopt` for an undocumented opcode; written by x/y/z/p/q fields (Dinu), with the documented `ED` list (40 of `40`–`7F`: not `4C 4E 54 55 5C 5D 63 64 65 66 6B 6C 6D 6E 70 71 74 75 76 77 7C 7D 7E 7F`; the 16 block opcodes) and the documented index forms (those naming `(IX+d)` or `IX` itself; 39 for each of `DD` and `FD`; `DD CB`/`FD CB` with op `& 7 == 6`, not `$36`: 31 each). UM0080's `ED 01dd1011`/`ED 01dd0011` include `ED 6B`/`ED 63` (`LD HL,(nn)`, `LD (nn),HL`) but the assembler gives the 3-byte `2A`/`22`, as every assembler does, so those two cannot round-trip and are left out of the list (the hand table has the `2A`/`22` rows). `std::vector<std::vector<std::uint8_t>> Z80DocumentedOpcodes()` enumerates them all (252 + 248 + 56 + 2 × 39 + 2 × 31 = 696) with operand bytes `n = $5A`, `nn = $1234`, `d = $FD` (−3), relative `e = $10`. Each: disassemble at `$0100`, assemble the text at `$0100`, the same bytes. A case also checks the count, 696.
- **On the core**: each of the 696 run on `Z80Core` from `$0100` (RAM of 64 KB, the bytes at `$0100`; BC, DE, HL, IX, IY `$8000`, SP `$9000`, interrupts off; `In` returns `$FF`) until `instructionEnded()`: the `Fetch` and `Read` addresses inside `$0100`–`$010F` are exactly `$0100` up to `$0100 + length − 1`.
- **Syntax**: `LD A,(BUF+1)` vs `LD A,(1+2)*3`; `LD A,(2)+(3)` immediate; `(IX)`, `(IX-1)`, `(IY+127)`, `(IX+128)` out of range; `JR *` is `18 FE`; a forward `JP` and `JR`; `EX AF,AF' ; it's`; `CP 'A'`, `LD A,','`; `LD HL,-1`; `LD A,256` out of range; `BIT 8,A`, `IM 3`, `RST 1` errors; `ADD B` and `SUB A,B` messages; `LD B,(SP)`, `JP C`, `LD (HL),(HL)` no form; `C = 5` then `LD A,C` loads from register C; `.cpu` unknown, twice, after an instruction; `lda #1` under `.cpu z80` and `LD A,B` under the 6502 unknown; every directive (`.byte`, `.word`, `.checksum`, `.include`) under `.cpu z80`.
- **Mutations** (plan, phase 2): the `DD CB d op` order swapped; `cc` shifted one bit off; `JR`'s offset from `pc` not `pc + 2`; each must fail a case.

`asm: every ROM program matches its committed .rom` takes `roms/bus_load_z80.asm` by iterating `roms/`; the ctest `asm_bus_load_z80` comes from `tests/CMakeLists.txt`'s `file(GLOB … CONFIGURE_DEPENDS *.asm)` (the next build re-runs CMake).

## Bus load

`roms/bus_load_z80.asm`: header comment from the script's docstring (the line and frame budget explained, what each part of the ROM holds); `.cpu z80`, `.rom $0000, $0800`; constants `IMAGE = $0100`, `DISPLAY_RAM = $4000`, `ROWS`, `TOP_ROWS`, `BOTTOM_ROWS`, `ROW_LINES = 8`, `R_LOAD = $80 - 35`, `DELAY = 120`, `IMAGE_SIZE` (6 + 24 × 33 + 8); the program at `$0000`, the handler at `.org $0038`, each line's T-states in its comment as the script had them; labels `frame`, `tail`, `same` in place of the script's addresses (`JR frame`, `CALL tail`, `JP NZ,same`, `DJNZ *`); the image at `.org IMAGE` as `.byte` rows (the HALTs, the title row's codes and each row with its `$76`); the glyphs at `.org $0600` as `.byte %…` rows, eight a character, from the `.rom`'s dot rows (one comment a code). The words must equal the old `.rom`'s: checked once in phase 3 with `ReadRomContents` on the old file (from git) and the new, not kept as a test (the old file is gone after).

The script's `--check` (the T-state budget, the R wrap) is not kept: the `bus load` tests run the program on the simulator and check the TV's lines and frames, which is what the budget is for.
