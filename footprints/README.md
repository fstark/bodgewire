# Footprints

The footprints `bw place` writes into a generated Board ([P4k](../docs/p4k-board-placement/BOARD_PLACEMENT.md)), one per package of the Part catalogue (`KicadFootprint` in `src/board/kicad_netlist.cpp`).

Copied unchanged from the KiCad 10.0.7 footprint libraries (`KiCad.app/Contents/SharedSupport/footprints/<Library>.pretty/`), so a generated Board does not depend on the installed KiCad.
